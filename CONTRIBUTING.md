# Contributing to PromptShield

Thank you for your interest in contributing to PromptShield! This document provides guidelines for contributing to this project.

## How to Contribute

### Reporting Issues

- Use the [GitHub Issues](../../issues) tab to report bugs or suggest features
- Provide a clear description of the issue
- Include steps to reproduce (for bugs)
- Include your environment details (Python version, OS, GPU availability)

### Submitting Changes

1. **Fork** the repository
2. **Create a feature branch** from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes** following the coding standards below
4. **Test your changes** thoroughly
5. **Commit** with a clear message:
   ```bash
   git commit -m "feat: add description of your change"
   ```
6. **Push** to your fork and submit a **Pull Request**

### Coding Standards

- Follow PEP 8 for Python code
- Use descriptive variable and function names
- Add docstrings to functions and classes
- Set random seeds for reproducibility
- Keep notebooks clean — clear outputs before committing

### Areas for Contribution

- **Dataset expansion** — adding more diverse prompt examples
- **Model improvements** — testing new architectures or hyperparameters
- **Multi-language support** — extending to non-English prompts
- **Documentation** — improving guides, examples, and tutorials
- **Testing** — adding unit tests and integration tests

## Code of Conduct

Please be respectful and constructive in all interactions. We are committed to providing a welcoming and inclusive experience for everyone.

## Questions?

Feel free to open an issue for any questions about contributing.
